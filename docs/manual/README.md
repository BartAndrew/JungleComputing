# Jungle Computing Documentation Library

Operational documentation for Jungle Core, Canopy, Network Observatory, Repair Network and the two MCP interfaces. These guides separate development implementation, verification evidence and future capabilities.

| Guide | Purpose |
|---|---|
| [Detailed user manual](USER_MANUAL.md) | Installation, first use, navigation, 3D, health, events, replay, checks, repairs, measurements and troubleshooting |
| [AI / MCP guide](MCP_GUIDE.md) | Both tool catalogues, stdio/HTTP setup, exact approval flow, host configuration and examples |
| [Operations runbook](OPERATIONS.md) | Logs, incidents, backup/restore, updates, tokens and retention |
| [Developer reference](DEVELOPER_GUIDE.md) | Repository map, APIs, payloads, events, MCP architecture and tests |
| [Release status](RELEASE_STATUS.md) | Implemented scope, verified checks, gaps and acceptance gates |

Start with the user manual for hands-on use, or the MCP guide when connecting an AI host. Read release status before treating a demo or design as production functionality.

Implementation: [MCP](../../core/mcp/README.md), [Core quickstart](../../core/README.md). Concepts: [Jungle documentation hub](../README.md).
